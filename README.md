A powerful, developer-friendly utility designed for manipulating recipes and tags through simple JSON configuration.
Reliable Recipes allows modpack creators to effortlessly add, remove, or modify recipes and tags using standard JSON
files—without the need for complex scripts (looking at you, KubeJS!).

## Documentation

Learn how to use Reliable Recipes, configure your JSON files, and master recipe actions on our wiki!

**[Modded Minecraft Wiki](https://moddedmc.wiki/en/project/reliable-recipes/latest/docs/reliable-recipes)**

## Features

* **Dynamic Recipe Control:** Remove hardcoded recipes or inject custom ones at runtime.
* **Tag Manipulation:** Add or remove items/blocks from tags via config files.
* **No Scripting Required:** Uses standard Minecraft-style JSON syntax for ease of use.
* **Cross-mod Compatibility:** Integrates seamlessly with mods like Reliable Removal and Item Obliterator.
