Reliable Recipes is a powerful tool designed to make manipulating recipes and tags simple and script-free.

## Core Features
* **Dynamic Recipe Control:** Remove hardcoded recipes or inject custom ones at runtime.
* **Tag Manipulation:** Add or remove items/blocks from tags via config files.
* **No Scripting Required:** Uses standard Minecraft-style JSON syntax for ease of use.
* **Custom Recipe Types:** Backports `crafting_transmute` and `minecraft:brewing` from newer versions to allow for item upgrades and data-driven brewing recipes.

## Mod Compatibility
Reliable Recipes plays nicely with several other utility mods out of the box:
* Automatically removes recipes and tags from items hidden with [Reliable Removal](https://www.curseforge.com/minecraft/mc-mods/reliable-remover)'s blacklist.
* Press the **delete key** while hovering over a recipe output in EMI (while in dev mode) to automatically generate a removal JSON.
